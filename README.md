# SecureSure Insurance — ISO 27001 GRC Portfolio

## Project Overview

This project demonstrates a simulated Governance, Risk and Compliance (GRC) implementation for a fictional insurance company using ISO/IEC 27001:2022 and ServiceNow capabilities available in a Personal Developer Instance (PDI).

## Objectives

- Information security policy development
- Information asset inventory and risk assessment
- ISO 27001 control mapping
- Control assessments, attestations and evidence collection
- Findings, corrective actions and remediation
- ServiceNow implementation documentation

## Disclaimer

This is a fictional learning and portfolio project. All organizational details, assets, risks, evidence and results are simulated. This project does not represent an actual certification or audit opinion.
